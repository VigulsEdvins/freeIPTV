# Мой Персональный IPTV Плейлист

Автоматически обновляемый M3U плейлист без новостей и политики.

## Состав каналов (всего ~380):
- 🍿 **Кинозалы и Фильмы** (~200 каналов): Кинозалы Kinowalk, Catcast, советское кино, фантастика, боевики, комедии, сериалы.
- 🎉 **Развлекательные** (~75 каналов): ТНТ, СТС, Пятница, 2х2, ТНТ4, СТС Love, Суббота, Че (включая версии с разницей во времени).
- ⚽ **Спорт** (~40 каналов): Матч!, Матч! Арена, Матч! Премьер, Матч! Футбол, Матч! Боец, Sport Baltic.
- 👶 **Мультфильмы и Детские** (~35 каналов): СТС Kids, мультфильмы 24/7, Карусель.
- 🇱🇻 **Латвия** (~25 каналов): LTV1, LTV7, Re:TV, TV Jurmala, Radio SWH TV, Sport 1 Baltic, Go3 Sport.

## Ваша ссылка для IPTV-плеера:
После загрузки на GitHub ваша ссылка для плеера будет:
```text
https://raw.githubusercontent.com/ВАШ_ЛОГИН/freeIPTV/main/playlist.m3u
```

## Как обновить вручную:
```bash
python3 build_playlist.py
```
*(Также настроено автообновление через GitHub Actions каждый день в 03:00)*
